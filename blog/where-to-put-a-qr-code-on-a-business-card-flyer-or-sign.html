Where to Put a QR Code on a Business Card, Flyer or Sign So People Scan It

GuidesNov 26·By Ilyes Tounsi, founder

A QR code scans reliably when it is big enough for the distance, has a clear margin, sits on a plain light background and has been tested on paper. Failed codes usually miss one of those four. Here's how to check each before you pay for printing.

Start with the right file

A low-resolution image is the first thing that goes wrong. A small PNG looks fine on a screen and turns soft once it's printed large, and soft edges are hard for a camera to read.

You want either a large PNG or a vector file. In Digital QR Card, the "Download QR for print" button in My Cards gives you a PNG with a white background, a PNG with a transparent background, and an SVG. The PNG is 2048 pixels wide, which at 300 dots per inch is about 6.8 inches. Use the SVG for anything large, because a vector file stays sharp at any size, and send it if your printer asks for vector art. The code includes its margin, so you don't have to add one.

Size: match the code to the scanning distance

A common rule of thumb is that a code should be about one tenth of the distance it's scanned from. Someone holding a flyer is about 25 centimetres away, so 2.5 centimetres is enough. A code read from 2 metres, like one on a shop window, wants to be closer to 20 centimetres across.

Squares matter as much as distance. The more squares a code has, the smaller each one is at a fixed size. The codes from the print download are dense, about 70 squares per side, because they carry a longer address and a high error-correction level. On a business card, start at 2.5 to 3 centimetres across and test the real print before you order.

Leave the quiet zone alone

Scanners use the blank margin to find the edges of the code. The standard asks for a margin four squares wide, and the print download from My Cards uses exactly that. Printing text, a border or a photo edge into that margin is one of the most common reasons a printed code fails.

So when you place the code in a design, give it room. If you're fitting it into a corner of a flyer, make the corner bigger, don't shrink the margin.

Contrast and background

Use a dark code on a light background. The camera is looking for a strong difference between the two, and a mid-grey code on a beige panel can fail in poor light even though it looks fine on your monitor. Some scanners also have trouble with light codes on dark backgrounds, so don't assume that an inverted code will work on every phone.

Avoid putting a code directly on a photo or a busy pattern. If the design needs it, put a solid white or light shape behind the code first. A transparent PNG is useful on a flat colour, but on a photo it's a recipe for trouble.

If you add colour or a logo with a design tool, keep the logo small. Our free QR code creator has logo and colour options. It builds codes with the highest error-correction level, which lets a code survive some damage, but every bit of a logo you place over the middle uses up that safety margin.

Where to put it, by surface

  • Business card. Put the code on the back, with your name and a short instruction on the front. A short line like "Scan to save my contact" tells people what will happen.
  • Flyer or menu. Put it near an edge or a bottom corner, where a thumb doesn't cover it and where people look after reading the offer. A code buried in the middle fold is hard to reach.
  • Poster or sign. Place it at about chest height for people on foot. A code at the top of a tall sign is too far away to scan. Never put a code where people will be scanning it while they drive.
  • Window or door. Glass reflects. Check it at different times of day, and if the code is on the inside of a window, test it from outside.
  • Slide or screen. Make the code large and leave it up for a while. Screens are backlit and forgiving, but a code shown from the back of a room needs the distance rule, too.
  • Packaging or a badge. Curved or creased surfaces bend the pattern. Flat is best, and glossy laminate can bounce light straight back at the camera.

Tell people what the code does

A bare code gets ignored. A few words next to it fix that: "Scan to save my contact", "Scan to book" or "Scan for the menu". Say what happens, and you'll get more scans than from a lone square of dots.

Test before you print

This takes five minutes, and it's what separates a code that works from one that only looked right on screen.

  1. Scan the design on your screen with your phone.
  2. Print one copy on ordinary paper at the real final size, and scan that.
  3. Scan it from the real distance, not from two inches away.
  4. Try a second phone, ideally an older one, and try it in dim light.
  5. If it's going on a surface with glare or a curve, test on that surface.

Only order the full print run once every one of those passes.

Print once, change forever

The cheapest fix for a failed code is to avoid the print run in the first place, and the second cheapest is to never need a second one. When the code points at a card you control, you can change your phone number, your link or your offer without touching the print. The squares stay put, and what sits behind them changes.
